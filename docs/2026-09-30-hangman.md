## Hangman (CLI)

Arquivo: `hangman/hangman.py`

| Função | O que faz |
|---|---|
| `choose_word()` | Sorteia uma categoria dentro de `WORDS_BY_CATEGORY` e, em seguida, uma palavra dentro dessa categoria. Retorna `(categoria, palavra)`. |
| `display_word(word, guessed_letters)` | Retorna a palavra mascarada, mostrando as letras já acertadas e `_` para as ainda não descobertas. |
| `draw_hangman(wrong_count)` | Imprime o desenho ASCII do boneco correspondente ao número atual de erros (`HANGMAN_STAGES`). |
| `ask_letter(guessed_letters)` | Lê uma letra do jogador, validando que é um único caractere alfabético e que ainda não foi tentado. |
| `play_round()` | Executa uma partida completa: sorteia a palavra, faz o loop de tentativas usando `ask_letter`/`display_word`/`draw_hangman`, e retorna `True`/`False` conforme o jogador descobre a palavra ou esgota as tentativas. |
| `main()` | Loop principal do jogo: chama `play_round()` repetidamente, mantém o placar de vitórias/derrotas e pergunta se o jogador quer jogar de novo até ele responder que não. |

Constantes de suporte: `RESET/GREEN/RED/YELLOW/CYAN/BOLD` (cores ANSI, mesmo padrão dos projetos anteriores), `WORDS_BY_CATEGORY` (dicionário categoria → lista de palavras), `HANGMAN_STAGES` (desenhos ASCII do boneco, do 0 ao número máximo de erros) e `MAX_ATTEMPTS` (derivado do tamanho de `HANGMAN_STAGES`).
